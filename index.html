圖書館書籍查詢系統

以圖書館日常作業為情境，練習資料表關聯、條件搜尋、彙總統計與借閱紀錄查詢。

22種書目
12位作者
10種分類
15筆借閱紀錄

一、案例背景

圖書館需要管理書目、作者、分類、館藏冊數與借閱紀錄。讀者希望能依書名、作者、出版社、分類或館藏狀態快速找到書；館員則需要查詢目前可借冊數、尚未歸還紀錄與熱門書籍。

系統使用者需求

  • 讀者：依關鍵字與篩選條件尋找書籍，查看書籍資訊及可借冊數。
  • 館員：查詢書目資料、作者、分類、借閱人與歸還狀態。
  • 管理者：統計分類書目數、借閱次數與熱門書籍。
本案例內建 22 筆虛構書目、10 種分類及 2015–2025 年出版年份，作為資料庫課程練習，不代表任何真實圖書館館藏。SQL 題目以 MySQL 8.0 語法撰寫。此單檔版的瀏覽器預覽使用 SQLite/WASM 執行 MySQL 與 SQLite 共通的查詢子集，並非連線到真正的 MySQL Server；MySQL 專屬語法及完整伺服器功能需在 MySQL 8.0 環境驗證。

二、使用方式

  1. 到「圖書館搜尋」以一般讀者角度查找書籍。
  2. 到「資料庫結構」查看 ERD、欄位定義及範例資料。
  3. 到「SQL 練習」搜尋題目、載入 SQL、執行並對照預期結果。

圖書館書籍搜尋

關鍵字會同時比對書名、作者與出版社；其他篩選條件會與關鍵字以 AND 組合。

借閱管理（館員）

辦理借書、還書並查詢借閱紀錄；操作會直接寫入資料庫，書籍搜尋、首頁統計與 SQL 練習即時同步。

請選擇書目並輸入借閱人。

資料庫 ERD 與關聯

BOOK 與 AUTHOR 為多對多關係，透過 BOOK_AUTHOR 連接；CATEGORY 對 BOOK 為一對多；BOOK 對 LOAN 為一對多。

箭頭由外來鍵（FK）指向被參照的主鍵（PK）；N 代表多、1 代表一。BOOK 與 AUTHOR 透過 BOOK_AUTHOR 形成多對多。

資料表欄位說明

資料表欄位鍵值／說明
BOOKbook_idPK，書目編號
BOOKtitle、publish_year、publisher、total_copies書名、出版年份、出版社、館藏總冊數
BOOKcategory_idFK → CATEGORY.category_id
AUTHORauthor_id、author_namePK 作者編號、作者姓名
BOOK_AUTHORbook_id、author_id複合 PK，分別 FK → BOOK、AUTHOR
CATEGORYcategory_id、category_namePK 分類編號、分類名稱
LOANloan_idPK 借閱紀錄編號
LOANbook_id、borrower、borrow_date、return_dateFK 書目、借閱人、借閱日期、歸還日期（NULL 表示未歸還）
